# FitnessTracker

FitnessTracker is a SwiftUI iOS app for workout planning, meal tracking, step counting and nearby gym discovery.

## Features

- Firebase Authentication for account management
- Firestore backend for user data, meals and workout plans
- Meal tracking using the Edamam Food Database API
- Nearby gym search using MapKit and MKLocalSearch
- Step counting using CoreMotion
- SwiftUI interface with Home, Fitness, Meal Tracker, Analytics and Settings screens

## Tech Stack

- Swift
- SwiftUI
- Firebase Authentication
- Firebase Firestore
- CoreMotion
- MapKit
- Edamam Food Database API
